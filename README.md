# Play Dice

A simple Flutter dice game. Roll two dice: if the total is **greater than 10** you win (happy image), otherwise you lose (sad image).

## Features
- Two dice shown with Material icons (light-purple rounded tiles)
- Roll button generates two random numbers from 1 to 6
- Reset button restores the initial state (dice 1 and 1, total 2, sad image)
- Win/lose message and image
- Dark theme with purple accent, responsive layout

## Prerequisites
- Flutter SDK 3.x (includes Dart 3)
- Android Studio with the Flutter and Dart plugins
- An Android emulator or a physical Android device

## Installation
```bash
cd play_dice
flutter create --platforms=android .   # generates the android/ folder only
flutter pub get
```

## Run
```bash
flutter run
```

## Game logic
1. Initial state: dice = 1 and 1, total = 2, image = `assets/sad.png`.
2. **Roll**: `Random().nextInt(6) + 1` for each die, total = die1 + die2, then `setState()`.
3. If `total > 10` (11 or 12) show `assets/happy.png` and "You Win!"; otherwise `assets/sad.png` and "You Lose".
4. **Reset**: sets everything back to the initial state with `setState()`.
